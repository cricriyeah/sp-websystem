### Reporte de revisión del commit `6810ee7`

Revisión contra el spec `docs/superpowers/specs/2026-10-12-apartado-temporal-cupo-design.md` (§2, §4.1 y §4.2):

---

#### 1. Tenancy y omisión de paquetes cruza-empresa
* **Archivo:línea**: `backend/apps/bookings/cupo/apartado.py:153-167`
* **Defecto**: El spec (§2 y §4.1) establece que los paquetes cruza-empresa están fuera de alcance v1 y no deben apartar demanda temporal. `construir_retrato_paquete` solo descarta si `getattr(reserva, 'orden_id', None) is not None`, pero **no verifica `paquete.es_cruza_empresa`** ni que `ps.servicio.empresa_id == reserva.empresa_id`.
  - **Bajo Postgres con RLS**: Al ejecutar bajo el contexto de `reserva.empresa`, `paquete.servicios_asociados.select_related('servicio')` intentará unir servicios de otra empresa que están ocultos por RLS, provocando omisiones silenciosas de filas o comportamiento anómalo.
  - **Sin RLS (SQLite o superuser)**: Si un paquete cruza-empresa se evalúa sin `orden_id`, añadirá componentes de la otra empresa a `salidas`. Luego, `demanda_apartada_del_dia(reserva.empresa, ...)` (que solo filtra por empresa de la reserva e itera el JSON sin validar `servicio_id`) sumará la demanda del servicio de la otra empresa a la flota de pangas de `reserva.empresa`.

---

#### 2. Caída no controlada por `ObjectDoesNotExist` (código muerto)
* **Archivo:línea**: `backend/apps/bookings/cupo/apartado.py:150-157`
* **Defecto**: 
  ```python
  if not getattr(reserva, 'paquete_id', None) and not getattr(reserva, 'paquete', None):
      return {"v": 1, "salidas": [], "habitaciones": []}
  ...
  paquete = reserva.paquete
  if paquete is None or not hasattr(paquete, 'servicios_asociados'):
  ```
  Si `reserva.paquete_id` tiene un ID asignado pero la fila correspondiente no existe en base de datos o está oculta por RLS para el tenant actual, `not getattr(reserva, 'paquete_id', None)` evalúa a `False`. En la línea 156, evaluar `reserva.paquete` no devuelve `None`, sino que lanza `Paquete.DoesNotExist` sin capturarse. La comprobación `if paquete is None` en la línea 157 es inalcanzable para ese caso.

#### 3. Suposición de tipo en fechas (posible `TypeError`)
* **Archivo:línea**: `backend/apps/bookings/cupo/apartado.py:172-173`
* **Defecto**:
  ```python
  fechas = (
      sorted(fechas_de_componente(reserva.fecha_inicio_paquete, ps.dia_estancia, ps.salidas))
      if ps.salidas > 1 else [reserva.fecha]
  )
  ```
  `fechas_de_componente` realiza `inicio + timedelta(...)`. Si `reserva` es una instancia en memoria o deserializada donde `inicio_paquete` o `fecha` es un `str` (formato ISO), se produce `TypeError: can only concatenate str to str`. A diferencia de `demanda_apartada_por_rango` (que hace `date.fromisoformat`), aquí no se normaliza a `date`.
